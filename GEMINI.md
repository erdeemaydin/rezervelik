# Project Guidelines & Memory

## Version Control Mandate
*   **Always commit changes systematically via Git:** At the end of every significant logical change or phase, run `git status`, stage the appropriate files, and commit them with descriptive, well-formatted commit messages.
*   **Keep tracking possible:** Do not leave massive amounts of code uncommitted. Separate commits into logical buckets (e.g., "Database schema updates", "Backend API additions", "Frontend UI improvements").
